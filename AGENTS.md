# Project Constraints

- **Technology stack**: plain HTML/CSS/JavaScript only, no frameworks or npm
- **Required files**: `index.html`, `style.css`, `script.js` (at project root)
- **Local server**: must be served with `python3 -m http.server 8000 --bind 127.0.0.1`
- **Responsive design**: support widths from 360px to 1280px wide
- **Accessibility**: all controls keyboard-operable with visible focus
- **Security/privacy**: no external CDNs, keys, or personal data
