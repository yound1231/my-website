# Bioinformatics for Data Science Students

## Purpose and Audience

This is a one-page educational website designed as a beginner’s guide for undergraduate data science students who are curious about applying their skills to biology and medicine. It introduces the field of bioinformatics and explores practical applications where data science intersects with the life sciences.

## Prerequisites

- [Python 3](https://www.python.org/) installed on your system
- A modern web browser (Chrome, Firefox, Safari, Edge, etc.)

## Getting Started

To view the website locally, follow these steps in a fresh terminal:

1. **Navigate to the repository directory:**
   ```bash
   cd /path/to/my-website
   ```

2. **Start the local server:**
   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. **Open in your browser:**
   Navigate to [http://localhost:8000](http://localhost:8000)

## Stopping the Server

To stop the local server, press `Ctrl+C` in the terminal where it's running.
